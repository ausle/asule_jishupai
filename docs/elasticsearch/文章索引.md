"analyzer": "ik_max_word",
"search_analyzer": "ik_smart"

建立倒排索引时，切的精细一点，使用ik_max_word分词器。
对搜索词进行分词时，切的聪明点，使用ik_smart分词器。

```
"title": {
    "type": "text",
    "analyzer": "ik_max_word",
    "search_analyzer": "ik_smart",
    "fields": {
      "keyword": {
        "type": "keyword",
        "ignore_above": 256
      }
    }
}
```
一个标题，保存了两套索引。
一个是title，text类型，支持全文搜索。
一个是title.keyword，keyword类型，精确匹配。
