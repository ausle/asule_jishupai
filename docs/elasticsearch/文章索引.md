### 分词器
"analyzer": "ik_max_word",
"search_analyzer": "ik_smart"

建立倒排索引时，切的精细一点，使用ik_max_word分词器。
对搜索词进行分词时，切的聪明点，使用ik_smart分词器。


```
"title": {
      "type": "text",
      "fields": {
        "keyword": {
          "type": "keyword",
          "ignore_above": 256
        }
      },
      "analyzer": "ik_max_word",
      "search_analyzer": "ik_smart"
    },
    "titleExact": {
      "type": "wildcard"
    },
```
一个标题，保存了两套索引。
一个是title，text类型，支持全文搜索。
一个是title.keyword，keyword类型，精确匹配。



### 用户搜索对应的ES查询语句

```
GET asule_article_v2/_search
{
  "from": 0,
  "size": 10,
  "query": {
    "bool": {
      "must": [
        {
          "bool": {
            "should": [
              {
                "wildcard": {
                  "titleExact": {
                    "value": "*Java*",
                    "case_insensitive": true,
                    "boost": 5.0
                  }
                }
              },
              {
                "wildcard": {
                  "shortTitleExact": {
                    "value": "*Java*",
                    "case_insensitive": true,
                    "boost": 4.0
                  }
                }
              }
            ],
            "minimum_should_match": 1
          }
        }
      ],
      "filter": [
        {
          "term": {
            "deleted": 0
          }
        },
        {
          "term": {
            "status": 1
          }
        }
      ]
    }
  },
  "_source": [
    "articleId",
    "title",
    "shortTitle",
    "summary",
    "content"
  ],
  "sort": [
    {
      "_score": {
        "order": "desc"
      }
    },
    {
      "updateTime": {
        "order": "desc",
        "unmapped_type": "date"
      }
    }
  ],
  "highlight": {
    "pre_tags": [
      ""
    ],
    "post_tags": [
      ""
    ],
    "fragment_size": 160,
    "number_of_fragments": 3,
    "fields": {
      "title": {},
      "shortTitle": {}
    }
  }
}
```

from: 0, size: 10：从第 0 条开始，最多返回 10 条。
must：必须满足标题或短标题至少一个字段匹配。
wildcard "*Java*"：只要字段内容中包含 Java 即可匹配。
case_insensitive: true：忽略大小写。
boost: 5 / 4：标题匹配的重要性高于短标题。
filter：- deleted = 0：未删除；
- status = 1：已上线或有效。

_source：限制返回的字段，避免返回无关数据。
sort：先按搜索相关度倒序，再按更新时间倒序。
highlight：返回标题和短标题中匹配位置附近的文本片段。由于前后标签为空，结果中不会显示明显的高亮标签。
